# Productivity App

## Overview
A cross platform productivity application built with Expo and TypeScript.

## Features
- Create tasks
- Delete tasks
- Mark tasks complete/incomplete
- Priority levels (High, Medium, Low)
- Task statistics
- Filter tasks
- Dark mode
- User settings
- Local data persistence

## Technologies
- Expo
- TypeScript
- Expo Router
- SQLite
- SecureStore
- NativeWind

## Setup

Install dependencies:

npm install

Run web:

npm run web

Run iOS:

npm run ios

## Testing

Platforms tested:
- Web (Chrome)
- iOS Simulator
