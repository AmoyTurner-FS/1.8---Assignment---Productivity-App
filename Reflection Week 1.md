# Reflection

The most challenging part of this assignment was making the application work correctly across both web and mobile platforms. At first, I assumed that if something worked on the web version, it would automatically work on iOS as well. However, I quickly learned that some features behave differently depending on the platform. For example, localStorage works on the web but not on iOS, and some navigation methods that worked in the browser caused errors on the mobile simulator. I had to spend time troubleshooting and creating platform specific solutions to make sure the app functioned properly on both platforms.

To handle the time constraint, I focused on completing the required features first before worrying about additional improvements. I started by setting up the project structure, then implemented task management, data storage, and navigation. After the core functionality was working, I moved on to the settings page, dark mode feature, and cross platform testing. Breaking the project into smaller tasks helped me stay organized and prevented me from getting overwhelmed.

If I had more time, I would improve the overall user interface and add additional features. I would like to add task editing, due dates, categories, and better visual feedback throughout the application. I would also spend more time refining the styling to make the application feel more polished and professional. Another improvement would be adding more robust error handling and validation for user input.

What surprised me most about the development process was how much time debugging can take compared to writing the actual code. Several issues were caused by platform differences rather than coding mistakes. I also gained a better understanding of how Expo, SQLite, SecureStore, and Expo Router work together in a real project. Although the assignment was challenging at times, it helped me become more comfortable with cross platform development and gave me practical experience building a complete application from start to finish. Overall, I learned a lot about planning, debugging, and testing applications across multiple platforms while creating a functional productivity app.
